# ALUR PANDUAN PENGISIAN APLIKASI SMART LTT (ROLE PPL)
**Fokus Pelaporan Mandiri Jagung & Ubi Kayu Serta Pemantauan Data Padi**

Berikut adalah langkah-langkah panduan pengisian dan pemantauan data LTT untuk petugas PPL:

---

### **1. Akses & Login Aplikasi**
* **Aksi:** Buka URL Web App SMART LTT di HP/Komputer lalu login menggunakan **NIP** dan **Password** Anda.
* **Visual:** Ilustrasi halaman masuk aplikasi (Login Screen).

### **2. Input Mandiri Jagung & Ubi Kayu**
* **Aksi:** Masuk ke menu **Input Data LTT**.
* **Langkah Input:**
  * **Pilih Tanggal:** Tanggal riil tanam/panen di lapangan.
  * **Pilih Desa:** Pilih desa sesuai lokasi pertanaman.
  * **Pilih Komoditas:** Hanya pilih **Jagung** atau **Ubi Kayu** (Padi tidak diinput manual).
  * **Masukkan Luas Tanam/Panen:** Tulis luasan dalam satuan Hektar (Ha).
  * **Kirim Laporan:** Klik **Kirim Laporan** dan pastikan status terkirim.
* **Visual:** Ilustrasi form input khusus komoditas Jagung & Ubi Kayu dengan ikon timbangan/hektar.

### **3. Pantau Hasil Sinkronisasi Padi (e-Pusluh)**
* **Aksi:** Masuk ke menu **Dashboard / Riwayat Padi**.
* **Penjelasan:** Data LTT Padi tidak diisi secara manual, melainkan ditarik otomatis dari sistem **e-Pusluh** oleh Admin Kabupaten.
* **Tugas PPL:** Memantau apakah data Padi desa wilayah binaan Anda hasil sinkronisasi e-Pusluh sudah sesuai atau belum.
* **Visual:** Ilustrasi layar sinkronisasi data (ikon awan/sync) berlabel "e-Pusluh".

### **4. Verifikasi & Riwayat Laporan**
* **Aksi:** Cek tabel **Daftar Laporan** untuk melihat status verifikasi data Jagung & Ubi Kayu yang Anda input:
  * 🟡 **Menunggu:** Laporan sedang ditinjau oleh pihak BPP/Kecamatan.
  * 🟢 **Disetujui:** Data valid dan sudah masuk rekap resmi kabupaten.
  * 🔴 **Ditolak:** Terdapat kesalahan data (klik tombol Edit untuk memperbaiki isian).
* **Visual:** Tabel daftar dengan indikator warna status verifikasi.
